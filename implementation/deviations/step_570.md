# Step 570 Green-Slice Deviation

Status: approved workflow adaptation
Affected checkpoints: `step_570` through `step_581`

The dynamic manifest regression cases require the new outcome model and
resolver to compile, while the active `pfc` workflow forbids committing a red
repository snapshot. The additive public types, internal static-selection
exposure, evaluator resolution, signed-event cases, no-fallback invariant,
advisory-only proof, documentation, and delivery permutations are therefore
committed as one green TDD slice.

No requirement is removed or weakened. Static NIP-01 replacement remains
available as a corpus query, while the evaluation report exposes the separate
stateful result. Missing, wrong-coordinate, dynamically invalid, canonical,
and valid-noncanonical references are distinguished without allowing a
manifest to affect canonical controls, accepted changes, heads, history, or
materialized state.
