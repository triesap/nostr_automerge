# ADR 0045: Registry V2 And External NIP Hold

Status: Approved

## Context

Nine reviewed semantics are absent from the ordered registry, while the NIP
prose is maintained outside this implementation program.

## Decision

Preserve the original 87 requirement identifiers in order and append nine rows.
Use companion authority for locally implemented semantics and keep the NIP
self-containment finding explicitly open.

## Consequences

Code work may proceed from complete companion authority. No evidence may claim
that unchanged NIP text proves the new rows or closes the external hold.
